# 안전보건 교육 (제조업) — 모바일 앱

한국어·Filipino·ไทย·Tiếng Việt 4개 언어로 보는 제조업(판금) 근로자용 안전보건 교재입니다.
휴대폰 홈 화면에 설치하면 앱처럼 열리고, 한 번 열어 두면 인터넷이 없어도 볼 수 있습니다.

## GitHub Pages로 올리기

1. GitHub에서 **New repository** → 이름 예: `safety-edu` → **Public** 선택 → Create
2. 저장소 화면에서 **Add file → Upload files** → 이 폴더 안의 파일과 폴더(`index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `icons/`, `img/`, `README.md`)를 모두 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, 폴더 **/(root)** → Save
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/safety-edu/` 주소로 열림

## 근로자 휴대폰에 설치하기

- **안드로이드(Chrome·삼성 인터넷)**: 주소를 열면 아래쪽에 "설치" 버튼이 뜹니다. 안 뜨면 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
- **아이폰(Safari)**: 공유 버튼 → **홈 화면에 추가**

주소를 QR코드로 만들어 휴게실·교육장에 붙여 두면 편합니다.

## 내용을 고친 뒤 다시 올릴 때

`sw.js` 첫 줄의 `safety-edu-v1`을 `v2`, `v3`처럼 올려 주세요. 그래야 이미 설치한 휴대폰도 새 내용으로 바뀝니다.

## 출처

- 내용: 산업안전보건법·시행령·시행규칙, 산업안전보건기준에 관한 규칙, 중대재해 처벌 등에 관한 법률, 근로기준법, 남녀고용평등법, 고용노동부 자료를 바탕으로 직접 작성
- 그림: 직접 그림. 안전보건표지는 시행규칙 별표 6의 색·모양 기준을 따름
- '올바른 예' 사진: Gemini로 생성한 AI 이미지(실제 현장 사진 아님)

## 학습 기록을 구글 시트로 모으기

앱에서 근로자가 **이름을 등록**하면, 단원을 "다 읽었어요"로 체크할 때와 퀴즈를 끝낼 때마다 구글 시트에 기록이 쌓입니다.
퀴즈를 끝내면 **이수 확인** 화면(이름·읽은 단원 수·퀴즈 최고점·일시)이 나와 관리자에게 보여 주거나 캡처해 보낼 수 있습니다.

1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `안전교육 기록`으로 정합니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 이 저장소의 `Code.gs` 내용을 그대로 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 승인(내 구글 계정 선택 → 고급 → 안전하지 않은 페이지로 이동 → 허용)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. GitHub 저장소에서 `config.js` 파일 → 연필(✏) 아이콘 → `sheetUrl: ""`의 따옴표 안에 URL을 붙여 넣고 **Commit changes**.
7. 1~2분 뒤 휴대폰에서 앱을 다시 열면 기록이 시트의 **기록**, **요약** 탭에 쌓이기 시작합니다.

- **요약** 탭: 사람(이름+기기번호)마다 한 줄 — 읽은 단원 수, 퀴즈 최고점, 마지막 기록 시간
- **기록** 탭: 이벤트마다 한 줄 — 시간, 이름, 기기, 언어, 종류(이름 등록/단원 완료/퀴즈), 내용, 점수
- 인터넷이 없을 때 읽은 기록은 휴대폰에 모아 두었다가 연결되면 자동으로 보냅니다.
- 이름과 학습 기록을 모은다는 안내가 이름 입력 칸 위에 4개 언어로 나옵니다.
